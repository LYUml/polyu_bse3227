# Airflow turndown arithmetic check

All 80 current terminal IDs retain their maximum-flow values. Each minimum flow equals 40% of that maximum within floating point representation tolerance. This uses the explicit assignment turndown instruction and the current declared design allocation.

The result is conditional on the maximum-flow allocation. It does not accept source geometry,actual room loads,diffuser throw,ADPI,controls or installation. Original project requirements and unresolved-input records remain preserved.
